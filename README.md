# ⚡ Jeu du Clic Rapide

Un mini-jeu réalisé en **HTML, CSS et JavaScript**.

Le but est simple : cliquer le plus de fois possible en **10 secondes** et essayer de battre son meilleur score.

---

## 🎮 Fonctionnalités

* 🖱️ Compteur de clics en temps réel
* ⏳ Chronomètre de 10 secondes
* 🏆 Meilleur score sauvegardé avec `localStorage`
* 🎉 Animation de confettis à la fin de la partie
* 🌙 Mode sombre / clair
* 🎵 Musique de fond activable/désactivable
* 📱 Interface responsive (ordinateur et mobile)

## 🚀 Installation

1. Clone le dépôt :

```bash
git clone https://github.com/votre-utilisateur/rapid-click-game.git
```

2. Ouvre le dossier :

```bash
cd rapid-click-game
```

3. Lance le projet en ouvrant `index.html` dans ton navigateur.

Aucune installation supplémentaire n'est nécessaire.

---

## 🎯 Comment jouer ?

1. Clique sur **Commencer**.
2. Clique le plus vite possible sur le gros bouton rouge.
3. Lorsque les 10 secondes sont écoulées, ton score s'affiche.
4. Essaie de battre ton meilleur score !
